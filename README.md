# Hospital Emergency Room (ER) Analytics Dashboard

## 📌 Overview
This Power BI dashboard provides real-time insights into hospital emergency room operations.  
It helps administrators, doctors, and staff monitor **patient flow, wait times, resource utilization, and outcomes** to improve efficiency and patient care.

## 🎯 Objectives
- Track **ER patient volume** by time, age group, and severity.
- Monitor **average wait times** from arrival to triage and treatment.
- Measure **bed occupancy and resource utilization**.
- Identify **admission vs. discharge trends**.
- Highlight **peak hours/days** for better staff scheduling.
- Enable **data-driven decision-making** to enhance patient care.

## 📊 Key Metrics (KPIs)
- **Total ER Visits**
- **Average Wait Time** (minutes)
- **Bed Occupancy Rate (%)**
- **Admission vs. Discharge Rate**
- **Patient Demographics** (age, gender, condition severity)
- **ER Utilization by Time (hour/day/month)**
- **Critical Case % vs. Non-Critical Cases**

## 📈 Dashboard Insights
- **Patient Flow:** Understand how many patients arrive daily/weekly, and when peak demand occurs.  
- **Wait Times:** Identify bottlenecks in triage and treatment processes.  
- **Capacity Planning:** Track bed occupancy to optimize staffing and resource allocation.  
- **Outcomes:** Compare admissions vs. discharges to evaluate ER efficiency.  
- **Demographics:** Analyze patient distribution to anticipate future needs (e.g., more pediatric/geriatric care).  

## 🛠️ How to Use
1. Open the `.pbix` file in **Power BI Desktop**.
2. Refresh data sources (Excel/Database/Snowflake as applicable).
3. Use slicers/filters (time, department, severity, demographics) to drill down insights.
4. Export visuals for reporting or presentations.

## 👤 Target Users
- Hospital Administrators  
- Emergency Room Managers  
- Healthcare Data Analysts  
- Medical Staff (Doctors, Nurses, Support Teams)
